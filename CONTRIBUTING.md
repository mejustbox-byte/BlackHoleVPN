# Участие в разработке

Предложения и сообщения об обычных ошибках оформляйте через GitHub Issues, указав версии Debian, Xray и клиента, ожидаемое и фактическое поведение и минимальные шаги воспроизведения. Перед публикацией удалите IP, идентификаторы, ключи и конфигурации подключения.

Для изменений создайте ветку и pull request с описанием задачи и результатов проверки. Документация должна соответствовать реально проверенному поведению; изменения развёртывания требуют проверки на чистой виртуальной машине и сценария отката. Не добавляйте исполняемые загрузки без закрепления версии и проверки источника.

Уязвимости сообщайте согласно [SECURITY.md](SECURITY.md), не раскрывая их в публичных issues.
