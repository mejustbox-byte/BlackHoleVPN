# Проверка BlackHoleVPN

## Локальный набор

Из корня репозитория запустите `python3 -m unittest discover -s tests -v`. Требуется Python 3, дополнительные пакеты не нужны. По умолчанию тесты управления используют локальный имитатор Xray, а тест реального Xray пропускается. Сообщение `OK (skipped=1)` не подтверждает совместимость с Xray или Debian 13.

## Реальный Xray на Debian 13

На изолированной тестовой машине установите доверенную, зафиксированную версию Xray-core из официального источника и проверьте её происхождение. Убедитесь, что доступен Python 3. Запустите:

```sh
xray version
BLACKHOLE_TEST_XRAY=/usr/local/bin/xray python3 -m unittest discover -s tests -v
```

Замените путь на фактический абсолютный путь проверенного бинарного файла. Тест создаёт временную ключевую пару и конфигурацию, проверяет init, добавление, валидацию и отзыв через настоящий Xray; временные данные удаляются. Он не запускает сервис, не слушает порты и не устанавливает соединение с example.org. Если формат вывода ключей Xray изменился, тест завершится ошибкой: это несовместимость теста, требующая проверки вручную.

До объявления релиза отдельно проверьте запуск systemd, клиентское VLESS/REALITY-соединение, DNS/IPv6 и разрыв соединения, отзыв доступа, firewall и SSH, перезагрузку, обновление, резервную копию и откат. Документируйте версию ОС, Xray и клиента и результаты, не публикуя адреса, ключи и профили. Сетевую устойчивость и поведение при DPI проверяют в каждой целевой сети отдельно.
