# Локальное управление подписками — эксперимент

Инструмент предназначен для тестирования, не для публичного развёртывания. Он не устанавливает HTTPS-сервер и не связывает подписку с Xray. Запускайте из корня репозитория от отдельного пользователя. Рабочий каталог должен принадлежать этому пользователю и иметь права 0700; файлы с профилями и токенами — 0600. Секретные файлы, база SQLite, её вспомогательные файлы и резервные копии должны храниться за пределами Git.

В приватном файле `profiles.json` задайте массив строк VLESS, например `["vless://...", "vless://..."]`, предварительно настроенных и проверенных на сервере. Реальные ссылки не публикуйте. Затем укажите абсолютные пути вместо примеров:

```sh
python3 -m blackhole.subctl --db /private/subscriptions.sqlite issue --profiles-file /private/profiles.json --token-file /private/device.token
python3 -m blackhole.subctl --db /private/subscriptions.sqlite update --profiles-file /private/profiles.json --token-file /private/device.token
python3 -m blackhole.subctl --db /private/subscriptions.sqlite revoke --token-file /private/device.token
```

`issue` не перезаписывает существующий файл токена и не печатает токен. `update` валидирует новый список до замены. `revoke` блокирует только получение подписки, а не скопированные профили: отзовите UUID в Xray и примените изменение отдельно. Не удаляйте токен до отзыва, если он ещё понадобится для управления. При внезапном прерывании процесса между записью базы и файла может понадобиться удалить тестовую базу и создать подписку заново; атомарность операции между файловой системой и SQLite не гарантируется.

База содержит профили в обратимом виде, даже если токены записаны как хеши. Модуль WSGI возвращает список профилей на `/s/<token>`, но без TLS и без защиты журналов, а готовый сервер в проекте отсутствует. Ограничьте доступ к файлам, не используйте реальные профили в тестах и не открывайте WSGI в интернет до внедрения HTTPS, ограничения запросов, отключения записи токенов во всех журналах и проверки безопасности. Автоматическое переключение клиента не реализовано.

Тесты: `python3 -m unittest discover -s tests -v`. Проверка с реальным Xray запускается отдельно согласно [инструкции тестирования](testing.md).
