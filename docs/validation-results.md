# Подтверждённые проверки прототипа

Дата: 29 октября 2026 года. Среда сервера: Debian 13.4, x86_64, Python 3.13.5, Xray-core 26.10.21. Исходная версия проекта: `09d9c05` с исправлением расширения временных конфигураций на `.json`. Приватные адреса, порты, UUID, ключи и профили в отчёт не включены.

## Результаты

| Проверка | Результат | Границы вывода |
| --- | --- | --- |
| `unittest discover -s tests -v` на VPS с `BLACKHOLE_TEST_XRAY` | 46/46, без пропусков | Включает настоящий Xray при init, добавлении, валидации и отзыве клиента |
| XHTTP + REALITY, `stream-one`, fingerprint `firefox` | pass | Настоящие процессы клиента/сервера, конфигурации из VLESS-профилей генератора |
| TCP + REALITY + Vision, fingerprint `firefox` | pass | Настоящие процессы клиента/сервера |
| HTTPS download/upload через каждый транспорт | pass | По 1 МиБ в каждом направлении; содержимое download и SHA256 upload проверены на контролируемом HTTPS-стенде |
| HTTPS к внешнему сайту через каждый транспорт | pass | Проверена TLS-валидация без отключения проверки сертификата |
| Прямое подключение внешнего Linux-клиента к публичным тестовым портам VPS | pass | Xray 26.10.21, без SSH-туннеля; одна доступная сеть и один VPS |
| Остановка сервера при активном Linux SOCKS-клиенте | pass | Явный SOCKS-запрос завершается ошибкой, прямого повтора нет; это не тест системного kill switch |
| Отзыв UUID из обоих inbound с перезапуском тестового экземпляра | pass | Новые соединения отклонены и в loopback-, и во внешнем испытании |
| REALITY target: TLS-сертификат, TLS 1.3, ALPN h2 | pass | Сетевая доступность в момент проверки; это не полный аудит target или fallback |
| Сохранение существующих служб и настроек доступа | pass | Службы продолжали работать; после очистки набор слушающих портов и файлы SSH/firewall/fail2ban совпали с исходными |

Конфигурации тестового стенда отличались от базового генератора: временные порты, ограниченные маршруты к HTTPS-стенду и внешней проверочной странице, ограничения скорости REALITY fallback. Для HTTPS-стенда на loopback была разрешена только одна TCP-пара адрес/порт через `freedom.finalRules`; в Xray этой версии частные и зарезервированные адреса по умолчанию блокируются. Это исключение не требуется для обычного выхода к публичным сайтам. См. [официальную документацию Freedom](https://xtls.github.io/en/config/outbounds/freedom.html).

Для проверки URI применялось преобразование параметров ссылок в конфигурацию Xray. Импорт URI в GUI-приложения этим не подтверждён. Одноразовые процессы завершены и секреты удалены; отдельно подготовленный стенд для ручных клиентских испытаний имеет собственный ограниченный срок жизни.

## Что ещё не проверено

- Windows, iOS, их приложения и встроенные ядра: [инструкция и таблица результатов](windows-ios-testing.md).
- Вторая серверная площадка, повторные измерения в целевых Wi-Fi/мобильных сетях, устойчивость к DPI.
- DNS/IPv6/WebRTC, TUN/kill switch и отсутствие утечек при сбоях.
- Полный анализ злоупотребления REALITY fallback; ограничение скорости не устраняет все риски.
- HTTPS-подписка, связанный отзыв подписки/UUID, автоматическое переключение маршрутов.
- Перезагрузка, обновление с откатом и восстановление на реальной инфраструктуре.

Эти результаты подтверждают ограниченную работоспособность двух транспортов. Они не означают готовность публичного релиза, универсальный обход блокировок, анонимность или отсутствие журналов ОС/хостинга.
