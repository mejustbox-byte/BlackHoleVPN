# Безопасность

Проект находится на стадии проектирования и не прошёл аудит. Не используйте примеры и будущие установщики для защиты критически важных данных до независимой проверки.

Секреты REALITY, идентификаторы клиентов, конфигурации и резервные копии храните вне репозитория с минимальными правами. При утечке отзывайте затронутые доступы и заменяйте скомпрометированные ключи. SSH-ключи, системные обновления, резервное восстановление и контроль сетевого доступа обязательны.

До публичного релиза владелец должен указать приватный канал для сообщений об уязвимостях. Не публикуйте реальные секреты и эксплуатационные подробности в открытых issues.

## Сообщение об уязвимости

Используйте приватное сообщение об уязвимости через вкладку Security репозитория, если эта функция включена. Если приватный канал недоступен, не публикуйте детали в открытом доступе: сначала попросите владельца проекта предоставить безопасный канал. Срок ответа и поддерживаемые версии будут определены после начала эксплуатации.
